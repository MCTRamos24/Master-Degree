## 📝 About the Notes

The goal of this repository is to create clear, structured, and high-quality study material for learning, revision, and exam preparation.

The notes may include:

- definitions and theoretical concepts;
- mathematical formulas;
- worked examples;
- diagrams and visual explanations;
- algorithms and pseudocode;
- comparison tables;
- implementation details;
- summaries of important concepts;
- additional explanations for difficult topics.

The documents are continuously refined to improve both technical accuracy and readability.

## 🛠️ LaTeX

Most documents are written using **LaTeX**.

Depending on the course, documents may also use:

- TikZ diagrams;
- external figures and assets;
- Python scripts;
- custom LaTeX commands;
- additional packages.

A typical document can be compiled with:

```bash
pdflatex CourseName.tex
```

or, when supported:

```bash
latexmk -pdf CourseName.tex
```
